# Jeeasy

Jeeasy is a subject-wise JEE Mains productivity checklist app.

## What it does

- Groups chapters by **Physics**, **Chemistry**, and **Mathematics**.
- Arranges chapters within each subject by **priority** (High → Medium → Low), then score.
- Lets you check off completed chapters.
- Shows progress stats and the next best target.
- Saves your progress in browser localStorage.

## Run

```bash
python -m http.server 4173
```

Open `http://localhost:4173` in your browser.
